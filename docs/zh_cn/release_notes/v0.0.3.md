# AI Gateway API v0.0.3（配额控制与限流增强版本）

AI Gateway API v0.0.3 是控制面组件的重要增强版本，专注于配额控制与限流管理功能，为多模型 AI 流量管理提供完整的资源管控能力。

## 新增（Added）

### 配额控制与限流核心能力

- **API-Key 配额管理**：支持为 API-Key 配置配额计划（Quota Plan），包括配额总量、重置周期、余额状态等
- **API-Key 限流策略**：支持配置 TPM（Token Per Minute）、RPM（Request Per Minute）和最大并发数限制
- **Entity 管理**：新增实体管理功能，支持层级结构（部门/团队/个人），可配置配额和限流策略
- **Entity-Type 管理**：定义 Entity 类型，支持 1-5 级层级关系
- **配额余额同步**：实现 Redis 与数据库的配额余额同步机制，支持定时重置和手动重置

### OpenAPI v1 接口

- `/api-keys`：完整的 API-Key CRUD 接口，支持配额计划和限流策略配置
- `/api-keys/{id}/quota-plan`：查询 API-Key 配额计划（含实时余额）
- `/api-keys/{id}/quota-plan/reset`：重置 API-Key 配额余额
- `/entity-types`：Entity 类型的创建、查询、更新、删除接口
- `/entities`：Entity 的创建、查询、更新、删除接口，支持层级结构
- `/entities/{id}/quota-plan`：查询 Entity 配额计划（含实时余额）
- `/entities/{id}/quota-plan/reset`：重置 Entity 配额余额
- `/models`：获取网关支持的 AI 服务模型列表

### Inner-API 接口

- `/configs/mod-api-key`：导出 API-Key 配置（含配额计划信息），供 BFE 节点拉取
- `/configs/rate-limit-policy`：导出限流策略配置，供 BFE 执行 TPM/RPM/并发限制检查

### 数据模型

- **QuotaPlan**：配额计划模型，包含 unlimited、pass_when_no_enough_quota、quota、unit、reset_period 字段
- **RateLimitPolicy**：限流策略模型，包含 enabled、rules（tpm、rpm、max_concurrency）字段
- **Entity**：实体模型，支持 name、type、parent_id、allow_models、block_models 等字段
- **EntityType**：实体类型模型，包含 type_name、description、level 字段

### 可观测性增强

- **Exception Logger**：新增异常日志记录，捕获主程序、定时任务和 HTTP 接口的 panic 信息
- **Panic Recovery**：全局 panic 恢复机制，确保服务稳定性

## 变更（Changed）

### API-Key 模型变更

- 新增 `unlimited_quota` 字段，支持无限配额模式
- 新增 `models` 字段，支持模型白名单配置
- 新增 `subnet` 字段，支持客户端子网限制
- 新增 `entity_id` 和 `entity` 字段，支持挂载到 Entity
- 新增 `quota_plan` 和 `rate_limit_policy` 字段，支持配额和限流配置

### 配额存储变更

- Redis 中存储的值改为表示**剩余配额**（remaining），而非之前的已使用量（used）
- 创建 API-Key/Entity 时，Redis 键值初始化为配额总量
- 重置配额时，Redis 键值恢复为配额总量

### 定时任务优化

- 配额重置调度器启动时立即执行一次检查
- 检查频率改为每分钟

## 修复（Fixed）

- 修复 API-Key 创建时 Redis 初始化逻辑，改为初始化为配额总量
- 修复 Entity 创建时 Redis 初始化逻辑，改为初始化为配额总量
- 修复配额同步时读取逻辑，改为读取剩余量而非已使用量
- 修复 Entity-Type 删除时未检查关联 Entity 的问题
- 修复错误码返回逻辑，确保 404、409、422 等错误码正确返回

## 安全（Security）

- 新增 Entity-Type 删除时的关联检查，防止误删被引用的类型
- 新增 Entity 删除时的子实体和 API-Key 挂载检查
- 新增异常日志记录，便于安全审计和问题排查

## 依赖（Dependencies）

- 无新增外部依赖

## 兼容性（Compatibility）

- 与 v0.0.1、v0.0.2 版本兼容
- OpenAPI v1 接口保持向后兼容
- Inner-API 接口为新增接口，不影响现有功能
