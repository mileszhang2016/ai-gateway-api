# Model Provider Type 测试用例设计文档

## 1. 模块概述

Model Provider Type 模块用于返回系统支持的 AI 模型提供商类型列表，供创建/更新 Cluster 时选择 `provider_type`。该模块由 v0.3.0 从 `/clusters` 中独立出来，仅包含一个只读列表接口。

## 2. 接口列表

| 编号 | 接口名称 | 方法 | 路径 | 说明 |
|------|----------|------|------|------|
| MPT-1 | 获取模型提供商类型列表 | GET | `/open-api/v1/model-provider-types` | 返回字符串数组 |

## 3. 测试用例统计

| 接口 | 测试用例数 |
|------|-----------|
| 获取模型提供商类型列表 | 3 |
| **合计** | **3** |

## 4. 认证方式

测试环境配置 `SkipTokenValidate=true`，所有请求无需携带认证头。

## 6. 获取模型提供商类型列表

### 6.1 接口信息

| 项目 | 值 |
|------|-----|
| 模块 | Model Provider Type |
| 接口名称 | 获取模型提供商类型列表 |
| 方法 | GET |
| 路径 | `/open-api/v1/model-provider-types` |
| 说明 | 返回系统支持的 AI 模型提供商类型标识列表 |

### 6.2 接口参数说明

#### 6.2.1 请求参数

无

#### 6.2.2 返回数据字段

| 参数名 | 类型 | 说明 |
|--------|------|------|
| - | []string | 字符串数组，每个元素为一个提供商类型标识 |

### 6.3 测试场景总览

| 编号 | 场景 | 测试类型 | 简要说明 |
|------|------|---------|---------|
| MPT-1-001 | 获取提供商类型列表 | 正常参数 | 返回非空字符串数组 |
| MPT-1-002 | 验证返回元素类型 | 返回数据 | 数组每个元素均为非空字符串 |
| MPT-1-003 | 非法 Method | 异常参数 | POST 请求应返回 404 或 405 |

### 6.4 测试场景详细设计

#### 6.4.1 MPT-1-001：获取提供商类型列表（正常参数）

##### 设计思路

验证 GET 接口基本功能，确认返回非空的字符串数组，包含常见提供商类型。

##### 前提数据准备

无

##### 执行步骤

1. 发送 GET 请求到 `/open-api/v1/model-provider-types`。
2. 验证响应状态码和返回结构。
3. 验证 `Data` 为非空字符串数组。

##### 请求参数

无

##### 预期返回结果

**ErrNum**：200  
**ErrMsg**：success

**Data 字段校验**：

| 字段 | 预期值 | 校验方式 |
|------|--------|---------|
| Data | 非空数组 | IsArray / NotEmpty |
| Data[0] | 非空字符串 | IsString / NotEmpty |

---

#### 6.4.2 MPT-1-002：验证返回元素类型（返回数据）

##### 设计思路

验证返回数组的每个元素均为字符串类型，且不为空，确保前端可安全使用。

##### 前提数据准备

无

##### 执行步骤

1. 发送 GET 请求到 `/open-api/v1/model-provider-types`。
2. 遍历 `Data` 数组，校验每个元素类型与内容。

##### 请求参数

无

##### 预期返回结果

**ErrNum**：200  
**ErrMsg**：success

**Data 字段校验**：

| 字段 | 预期值 | 校验方式 |
|------|--------|---------|
| Data | 数组 | IsArray |
| Data[*] | 非空字符串 | IsString / NotEmpty |

---

#### 6.4.3 MPT-1-003：非法 Method（异常参数）

##### 设计思路

验证该只读接口不支持 POST，请求应返回 404 或 405。

##### 前提数据准备

无

##### 执行步骤

1. 发送 POST 请求到 `/open-api/v1/model-provider-types`，Body 为空对象。
2. 验证返回错误码。

##### 请求参数

```json
{}
```

##### 预期返回结果

**ErrNum**：404 或 405  
**ErrMsg**：包含 method not allowed 或 not found  
**Data**：null

---

## 7. 依赖与数据准备

无特殊依赖，该接口为只读工具接口。

## 8. 注意事项

1. 该模块替代了旧版 `/model-providers`（在 clusters 模块下）。
2. 返回的具体类型可能由配置文件或代码常量决定，测试用例不要硬断言完整列表，只需断言返回为非空字符串数组且元素类型正确。
3. 测试环境 `SkipTokenValidate=true`，无需认证头。
